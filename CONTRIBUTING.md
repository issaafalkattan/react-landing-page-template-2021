# Contributing to React Landing Page Template 2021

Thank you for your interest in contributing to this React landing page template! Contributions are welcome.

## Getting Started

1. **Fork** this repository
2. **Clone** your fork: `git clone https://github.com/YOUR-USERNAME/react-landing-page-template-2021.git`
3. **Install dependencies**: `npm install`
4. **Start dev server**: `npm start`

## Development Setup

### Prerequisites

- Node.js >= 14.x
- npm >= 6.x

### Available Scripts

```bash
npm start        # Start development server
npm run build    # Build for production
npm test         # Run tests
```

## How to Contribute

### What We Welcome

- **Design improvements** — Better responsive layouts, modern CSS enhancements
- **New sections** — Testimonials, pricing tables, FAQ accordion, team section
- **Accessibility** — ARIA labels, keyboard navigation, color contrast fixes
- **Performance** — Image optimization, lazy loading, code splitting
- **Bug fixes** — Layout issues, broken links, cross-browser compatibility
- **Documentation** — Better README, component usage examples

## Pull Request Process

1. Create a feature branch: `git checkout -b feat/your-feature`
2. Make focused, atomic commits
3. Test responsiveness across mobile, tablet, and desktop
4. Include screenshots for visual changes
5. Submit a PR with a clear description

### Commit Format

- `feat: add testimonials carousel section`
- `fix: correct hero image overflow on mobile`
- `style: improve button hover transitions`
- `docs: add deployment instructions`

## Code Style

- Use **functional React components** with hooks
- Follow existing project structure
- Use **CSS modules** or styled-components as per existing patterns
- Keep components **small and reusable**
- Use semantic HTML elements
